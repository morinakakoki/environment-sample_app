# スコアリング規則（task-triage）

1 タスク = U + I + C + Q（上限 100・下限 0）。内訳を必ず行ごとに残す。

## U 緊急度（期限までの日数。今日 = JST）
| 状態 | 点 |
|---|---|
| 期限超過 | 40 |
| 今日 | 35 |
| 1〜2 日後 | 30 |
| 3〜7 日後 | 20 |
| 8〜14 日後 | 10 |
| 15 日以上先 / 期限なし | 0 |

- 繰り返し枠（学習ブロック・SQL 用語 3 問・週次チェック）に紐づく「今日の中身」は「今日」扱い。
- 「〜まで」「M/D」のない手入力タスクは期限なし。

## I 重要度（何に効くか）
| 状態 | 点 |
|---|---|
| 転職の判断ポイント／LINE 構築のレビューゲート／コンペ (10/3) 逆算に直結 | 30 |
| 転職計画 §1-2 の今週 W の項目、または LINE 構築の今週提出物 | 25 |
| 金銭・アカウント停止（決済失敗、請求期限超過、サービス停止予告） | 25 |
| 生活・事務（レポート提出、手続き、本人確認） | 10 |
| 情報・興味（メルマガ、案件紹介、PR） | 0 → 表に載せない |

## C 放置コスト（取り返しがつくか）
| 状態 | 点 |
|---|---|
| 不可逆・連鎖（提出ゲートを逃す、GCP 停止でパイプラインが止まる、面接日程を逃す） | 20 |
| 遅延料金・信用低下・再手続き | 10 |
| なし（いつでも取り返せる） | 0 |

## Q 着手しやすさ（所要時間）
| 状態 | 点 |
|---|---|
| 15 分以内 | +10 |
| 16〜60 分 | +5 |
| 61〜180 分 | 0 |
| 181 分以上 | −5（分割候補として明記） |

## 振り分け
| tier | 点 | 意味 |
|---|---|---|
| 🔴 | 70 以上 | 今日中 |
| 🟠 | 50〜69 | 今週 |
| 🟡 | 30〜49 | 視野に入れる（来週以降・先の判断ポイント） |
| ⚪ | 29 以下 | バックログ |

上限規則:
- 期限が **15 日以上先** のタスクは 49 点で頭打ち（🟡 止まり）。判断ポイントや 11/1 有料化のように C=20 でも 🟠 以上にはしない。期限超過は対象外。
- 依存先（depends_on）が未完のタスクは、依存先の tier を超えない（例: S-2-5 は S-2-3 より上に来ない）。

同点の順: ① 期限が早い → ② 本人の圧縮順（LINE 構築: 競合社数 → ペルソナ数 → シナリオ分岐数 の順に削る。転職: 実装 > SQL 書く > 用語）→ ③ 所要が短い。

## 本人ルールによる上書き（転職計画.md・カレンダー説明文に明記されたもの）
- 転職ブロック週 12h が 2 週連続未消化 → タスク「全体計画チャット（Fable）に戻る」を 🔴 で追加。
- 進捗ログで 🟡 のまま 14 日以上更新なしの項目 → タスク「次セッションの 1 問目に回す」を 🟠 で追加（SQL は「書く問題に回す」）。
- GCP 無料トライアル終了 2026-11-16。11/1「有料化＋カスタム割り当て」は C=20 固定。
- 9/28〜10/4 はコンペ週。転職ブロックは 12h → 8h に減速（今日の枠計算に反映）。
- 「待ち」（講師 FB 待ち、返信待ち、受付完了）はスコアを付けず別表。期限が来たら催促タスクとして復帰。
