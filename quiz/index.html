問題を追加

Claude に「データ方式に as-of ジョインを実装した。quiz-data.json 形式で3問作って」 のように、どの方式に何を足したかを伝えて頼み、返ってきた JSON をそのまま 貼り付けてください。1問だけの {…} でも、複数問の […] でも取り込めます。

Notion の「復習クイズ 問題ストック」に行を足す方法もあります。そちらは貼り付け不要で、 次にこのアプリを開いたときに自動で増えます（アーティファクトとして開いているときだけ）。

この画面では直接保存できません（アプリとして公開されているときだけ保存できます）。 下のボタンで 追記後の quiz-data.json 全文 をコピーして、ファイルに貼り替えてください。

取り込みのルール

  • id は既存とかぶらない値に。かぶった問題は取り込まれません
  • chapter は基礎知識ノートの章番号。新しい章の番号でもそのまま増えます
  • tag は #14 でも as-of のような語でも構いません
  • method に方式設計書の方式名を入れてください。入れないと「方式別に解く」に出てきません（構成・前提 / 処理方式 / データ方式 / 認証・権限方式 / 運用・監視方式 / コスト方式 / IaC方式 / 設計判断）
  • 解説で選択肢を指すときは「選択肢2が誤り」ではなく内容で書いてください。出題ごとに選択肢の並びが変わります
  • 4つの選択肢は長さをそろえてください。正解だけ長いと、中身を知らなくても当てられます

定着率＝いま覚えている見込みの割合。正解しても間隔（3日→1週→2週→1か月…）を過ぎると 外れるので、放っておくと下がります。下がった分は「そろそろ復習」に出てきます。

カバー率と定着率の推移

正答率の推移はあえて出していません。このアプリは間違えた問題を優先して出すので、 上達するほど難しい問題ばかり並び、正答率は上がりません。伸びているかどうかは 上の2本で見てください。
