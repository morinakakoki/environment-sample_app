前提は「SQL・Docker・cron・AWS の IAM の概念は知っている。DWH と GCP は初めて」。各章の先頭に用語カードを置いたので、本文の比喩（Athena、ECS など）を知らなくても読める。

この章の用語
プロジェクト
GCP の基本の入れ物。リソース・課金・権限・API 有効化はこの単位で決まる
請求先アカウント
支払い方法を登録した「財布」。複数プロジェクトを紐づけられる
API 有効化
「このプロジェクトでこのサービスを使う」と宣言する操作。しないと呼べない
IAM
権限管理。「誰に・どのロールを・どこで」の3つ組で表す
ロール
細かい権限を用途ごとに束ねたもの（例：bigquery.dataEditor＝テーブル読み書き）
サービスアカウント（SA）
プログラム用のアカウント。メール形式の ID を持ち、リソースにアタッチして使う
無料トライアル／無料枠
トライアル＝期限付き $300。無料枠＝期限の無い毎月の無料分（別物）
この章の用語
BigQuery
SQL で大量データを分析するデータウェアハウス。保存と計算が分かれている
課金バイト
クエリが読んだデータ量。BigQuery はこれに課金する（保存料とは別）
データセット
テーブルの入れ物。リージョン（置く地域）を持つ
ジョブ
BigQuery への依頼1回。ロード（入れる）・クエリ（読む）・エクスポート・コピーの4種
maximum_bytes_billed
クエリ1本が読んでよいバイト数の上限。超えるなら実行しない
dry run
実行せずに「何バイト読むか」だけ見積もる。無料
パーティション
テーブルを日付などで内部的に区切る仕組み。絞れば読む量が減る
WRITE_TRUNCATE／APPEND
ロード時の書き方。全部消して入れる／後ろに足す
スキーマ／autodetect
列名と型の定義／ロード時にデータから型を推定する機能
この章の用語
Cloud Run Job
コンテナを起動して処理し、終わったら止まる実行サービス（Service は常駐型）
イメージ
コード＋ライブラリ＋OS 最小構成を1つにまとめた、コンテナの元
Artifact Registry
イメージの置き場。push で置き、Job が pull する
Cloud Scheduler
指定時刻に HTTP リクエストを1本送るだけの cron
トークン（OAuth／OIDC）
HTTP に付ける「呼び出し側が誰か」の証明。Google API なら OAuth、自前なら OIDC
Secret Manager
API キー等の秘密情報の保管庫。Job の環境変数に展開できる
この章の用語
IaC
インフラ構成をコードで書き、ツールに作らせる方式
Terraform
宣言型の IaC。「あるべき状態」を書くと差分を作る・変える
state（tfstate）
宣言と実際のリソースの対応表。Terraform が自分で持つ
plan／apply
変更内容を表示するだけ／実際に変更する
replace（-/+）
作り直し。テーブルなら中身が消える
ドリフト
Terraform の外から実体が変わり、宣言とズレること
この章の用語
raw／staging／mart
加工前のまま／型を揃え整形／見せる形に集計、の3層
冪等（べきとう）
同じ処理を何回やっても結果が同じ性質。再実行してよい根拠
as-of ジョイン
「その日時点で知り得た最新の値」を付ける結合
ルックアヘッド
まだ公開されていない情報を過去の日に付けてしまう誤り
dbt
SQL の変換をモデルとして管理し、依存（ref）とテストを付けるツール
ASSERT
SQL で条件を検査し、偽ならジョブを失敗させる文
この章の用語
予算アラート
月額がいくらを超えたら通知する設定。止めはしない
maximum_bytes_billed
クエリ1本の読み取り上限。実行前に拒否
カスタム割り当て
プロジェクト（またはユーザー）の1日の読み取り上限。おおよその値
